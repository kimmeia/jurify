Por que só acontece com uma funcionária

1 · o cargo
Milena só vê os clientes dela
O cargo dela é "ver apenas os próprios". Os outros veem todos — por isso só ela trava.
2 · o servidor
Responde "não pode ver"
O lead não está sob responsabilidade dela, então o servidor devolve vazio. Está correto — é a regra de acesso funcionando.
3 · a tela
Confunde vazio com carregando
Aqui está o defeito: a tela mostra o spinner enquanto não tiver dado. "Sem permissão" nunca deixa de ser "sem dado" — então gira para sempre.
4 · o conserto
Separar as duas coisas
Spinner só enquanto a resposta não chegou. Chegou e veio vazio → a mensagem acima. Vale para a tela inteira, não só este caso.
